Project Objectives

Synthesize

Build a square wave signal mathematically using Fourier Series by summing odd harmonics (1st, 3rd, 5th, ... up to 15th) to approximate the periodic waveform.

Analyze

Examine the frequency spectrum of the synthesized signal using Fast Fourier Transform (FFT) to identify and visualize the harmonic components.

Filter

Process the signal by applying a Butterworth Low-Pass Filter to remove high-frequency harmonics and observe the transformation back into a smooth sine wave.

Mathematical Foundation

The mathematical representation of a square wave using Fourier Series (Odd Symmetry):

$$f(t) = \frac{4A}{\pi} \sum_{n=1,3,5,...}^{N} \frac{1}{n} \sin(n \omega_0 t)$$

Parameters

  • A: Signal Amplitude
  • N = 15: Number of harmonics used
  • n: Odd integers only (1, 3, 5...)

Key Variables

  • \(\omega_0 = 2\pi f_0\) : Angular frequency (rad/s)
  • \(f_0 = 10 \text{ Hz}\) : Fundamental frequency
  • t: Time variable (seconds)

MATLAB Code: Synthesis

fs = 1000; % Sampling frequency (Hz) t = 0:1/fs:0.5-1/fs; % Time vector f_sig = 10; % Fundamental frequency (10 Hz) w0 = 2 * pi * f_sig; % Angular frequency A = 1; % Amplitude x_fourier = zeros(size(t)); N_harmonics = 15; % Number of odd harmonics % Build square wave by summing odd harmonics for n = 1:2:N_harmonics x_fourier = x_fourier + (1/n) * sin(n * w0 * t); end x_fourier = (4 * A / pi) * x_fourier; % Final scaling

Key Note: We synthesize the signal mathematically using a FOR loop instead of built-in functions to prove the Fourier concept.

MATLAB Code: FFT & Filtering

% --- 1. FFT Analysis --- N = length(x_fourier); X = fft(x_fourier); X_mag = abs(X(1:N/2+1))/(N/2); % Magnitude spectrum f_axis = fs*(0:(N/2))/N; % Frequency axis % --- 2. Low-Pass Filter Design & Application --- filter_order = 4; fc = 20; % Cutoff frequency: 20 Hz % Create Butterworth 4th order LPF [b, a] = butter(filter_order, fc/(fs/2), 'low'); % Apply filter to the synthesized signal y_filtered = filter(b, a, x_fourier);

\(\mathbf{f_c = 20 \text{ Hz}}\) : Safely passes the 10Hz fundamental frequency, while effectively blocking 30Hz, 50Hz, and higher harmonics.
